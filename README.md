# Project Based Learning (PBL)

## About

This repository contains the work completed by our team as part of the Project Based Learning (PBL) course.

The project focuses on implementing and understanding important Operating System concepts using the C programming language. It includes theoretical assignments, practical implementations, testing, and documentation.

## Project Modules

- **Doc:** Theoretical assignments and documentation.
- **Week 1:** Multi-Process Simulator and Inter-Process Communication (IPC).
- **Week 2:** Process Scheduling Simulator.
- **Week 3:** Deadlock Simulation System.
- **Week 4:** Page Replacement Algorithms.

## Technologies Used

- C Programming
- Linux / Ubuntu
- Visual Studio Code
- Oracle VirtualBox
- Git and GitHub

## Objective

To gain practical knowledge of Operating System concepts through programming, teamwork, implementation, and testing.

## Conclusion

This project helps us understand how Operating Systems work and improves our programming, problem-solving, and teamwork skills.
